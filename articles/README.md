# articles/

Your research agent stages the reference articles you collect here — each as a PDF plus an extracted-text copy it can search. This is what lets your agents quote from and reason over the actual papers.

These files stay **on your computer only** — they are not pushed to GitHub (see the workspace `.gitignore`), because the PDFs are copyrighted and your agent re-fetches them locally whenever needed. If you move to a new machine, your research agent re-stages them. (This folder keeps its README so it always exists.)
