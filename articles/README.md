# articles/

Your research agent stages the reference articles you collect here — each as a PDF plus an extracted-text copy it can search. This is what lets your agents quote from and reason over the actual papers.

These files **live in your workspace and sync to Google Drive along with the rest of it.** They are copyrighted papers you accessed for your own research, kept in your own Drive — that's ordinary personal use, and syncing them is a convenience: they follow you to any machine you work on. If you ever start fresh on a new machine before they've synced, your research agent can re-stage them locally with `fetch-articles`. (This folder keeps its README so it always exists even when empty.)

*Note: the `.gitignore` file in this workspace is a leftover from an earlier git-based setup and no longer governs anything — your workspace is synced by Google Drive, not git.*
